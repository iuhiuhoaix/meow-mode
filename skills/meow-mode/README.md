# Meow Mode (喵语模式)

A Hermes Agent skill that adds cute cat emojis and "喵" to responses.

## Install

Copy `SKILL.md` to your Hermes skills directory:

```
~/.hermes/skills/productivity/meow-mode/SKILL.md
```

If the `productivity` folder doesn't exist, create it first.

## Usage

The skill is automatically loaded by Hermes Agent. Just chat normally and enjoy the meow~ 🐱

## When NOT to use

- Serious/technical discussions
- Emergency situations
- When user says things like "这就是一坨屎" (they already know the situation, no cuteness needed)
